Pourquoi LikeC4 ?

100% Open source,
zéro enfermement

  • Licences libres & pérennes : code ouvert sous licences permissives (MIT / Apache)
  • Indépendance totale : aucun abonnement cloud obligatoire, fonctionne 100% en local et dans vos runners CI/CD
  • Interopérabilité native : exports immédiats vers D2, PlantUML, Mermaid, PNG, JSON et app React autonome
  • Souveraineté de vos données : vos modèles restent sécurisés dans vos dépôts Git, sans fuite de secrets

Partage & dynamisme

Un écosystème vivant,
contributions bienvenues !

  • Packs & spécifications : partagez vos briques transverses (packs cloud AWS/GCP, conteneurs métiers, règles)
  • Outillage & IA : enrichissez l'extension VS Code, les serveurs MCP et les agents Copilot
  • Retours du terrain : une feuille de route alimentée en continu par les besoins réels des équipes d'architecture
  • Prenez la main : testez dans vos projets, proposez vos idées et rejoignez la communauté !
